How it works

  1. A small client runs every hour on each machine. It reads the usage data that ccusage finds on that machine and adds up the tokens for the current cycle.
  2. The client sends that total to one dashboard. It sends token counts. It does not send prompts or code.
  3. You enter the percentage your provider shows, or the macOS menu bar app reports it. The dashboard divides it among your groups and machines by the tokens each one measured.

The dashboard

A menu bar app, useful with one Mac

You do not need several machines. On a Mac, a native menu bar app keeps your usage in view, reads the provider's own figure and reports for that Mac.

In the menu bar
The cycle's percentage as a number, with the provider's 5-hour window as a ring around it. Each turns orange past the warning level and red when critical.
In the popover
How much you have used and what is left, whether your pace runs out before the reset, and when the reset comes. With one machine it leaves out the breakdown by group and machine.
Reads the official figure
The app reads the limits that Codex and Claude Code record on your Mac and sends them to the dashboard, so you do not type the percentage in. Claude Code needs one changed line in its status line setting.
Reports for this Mac
It sends this Mac's usage every hour with the same reporter as the script, so the Mac needs no cron job.
Small and native
One process, no dependencies, under 1 MB. It runs on macOS 14 or later, in English, Hungarian and German.
You build it
There is no download. One script builds the app on your Mac, and the Command Line Tools are enough.

The app shows a dashboard's figures, so it needs the hosted instance or your own. See the app's README for the build and the first run.

Hosted or your own

Both run the same code. They differ in who runs the server and who holds the data.

Hosted Your own
Cost Free. A private individual runs it, with no warranty and no uptime guarantee. Free to use. You pay for the hosting, if your hosting costs anything.
Sign-in GitHub. The service stores your GitHub user id and login, not your e-mail address. A PIN or passphrase. GitHub sign-in for several users is optional.
What leaves your machine The machine's name, its group, the provider, token counts per model and per day, a cost estimate and the time of the report. No prompts and no code. The same report, sent to your server.
Where it is stored At Vercel and Upstash, both in Frankfurt. In the Redis database you set up.
Limits 25 machines, 20 providers, 20 groups and 10 members per workspace. Higher caps: 200 machine entries, 20 providers and 50 groups.
Retention Raw reports for 70 days. Per-cycle summaries until you delete the workspace. The same 70 days for raw reports. The summaries stay.
Leaving The account page downloads everything as one JSON file, and an empty instance of your own can import it. Deleting your account removes your data at once. The database is yours. The dashboard exports each cycle as CSV or JSON.

Before you sign in to the hosted instance, read its privacy notice and terms of use.

Providers and clients

Providers
Claude, OpenAI (Codex), Gemini, DeepSeek, Kimi, Meta, Mistral, Qwen and xAI. Any other provider that ccusage reports shows up under its own name.
macOS and Linux
An hourly cron job. The installer comes from the dashboard's Setup page as a ZIP or as text to copy.
Windows
An hourly Task Scheduler task, installed by a PowerShell script from the same Setup page.
Without installing
One command sends a single report and leaves nothing behind on the machine.
Alerts
A webhook call when usage crosses a threshold: 50, 80 and 100% by default, formatted for Slack or Discord, or as plain JSON.

Questions

Does it read my prompts or code?
No. The client sends token counts, model names, the machine's name and a cost estimate.
Does it need access to my provider account?
No. ccusage reads the logs that the coding agents already write on your machine.
Is the cost figure my bill?
No. It is an estimate from API list prices, and the dashboard hides it by default. A subscription does not bill per token.
Can I move from the hosted instance to my own?
Yes. Download your data on the account page and import the file into an empty instance.
Is it open source?
The source is public under the PolyForm Noncommercial License 1.0.0. It is free for personal and other noncommercial use. It is not OSI open source, and commercial use needs separate permission.
